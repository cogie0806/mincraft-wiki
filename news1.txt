Minecraft Java Edition 26.4 スナップショット概要

Minecraft Java Edition 26.4（2026年第4弾のゲームドロップ）に向けたスナップショット段階での主な変更点や技術的アップデート、仕様変更のまとめです。

1. グラフィック・システム基盤のアップデート

VulkanがデフォルトグラフィックAPIに設定: 26.4 Snapshot 1より、レンダリング基盤としてVulkanがデフォルトのグラフィックAPIに採用され、パフォーマンスや安定性の向上が図られています。

空の描画の調整: Snapshot 2では、オーバーワールドにおいて空の描画（スカイボックス）の下半分が太陽、月、星などの天体オブジェクトを遮蔽（オクルージョン）する仕様に変更されました。

2. ブロック・仕様の変更

キノコ配置の仕様緩和: 赤色および茶色のキノコが、周囲の明るさに関係なく、上面が固体のブロックの上に設置できるようになりました（※周囲への増殖条件はこれまで通り明るさレベル12以下である必要があります）。

3. 長年のバグの修正

13年越しのバグ修正: Java版で13年間放置されていた、水の中でのジャンプや移動挙動に関する古いバグ（MC-8959など）がついに修正され、ゲームプレイの挙動が一部調整されました。
